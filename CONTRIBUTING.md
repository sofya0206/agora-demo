# Агора — фронтенд

Продукт
B2B-каталог транспортной упаковки. Закупщик находит поставщиков, сравнивает предложения по цене и условиям поставки, собирает заявку и отправляет её поставщикам. Пилотная вертикаль — гофрокороба, плёнки, скотч, паллеты, этикетки: 14 категорий.
Стек
Next.js 16.2 (App Router), React 19.2, TypeScript strict
Tailwind CSS v4 (через @tailwindcss/postcss, без tailwind.config)
shadcn/ui поверх Radix, base color neutral
framer-motion — только на лендинге
lucide-react — иконки
Next 16 сильно отличается от предыдущих версий: изменились API, соглашения и структура файлов. Перед правками смотрите документацию в node_modules/next/dist/docs/ — в частности params и searchParams теперь асинхронные.

API
База: NEXT_PUBLIC_API_URL, по умолчанию https://agora.178.88.115.213.sslip.io/api. Все запросы идут через src/lib/api.ts — новые тоже добавляем туда, а не в компоненты.
GET /categories → { data: Category[] }
GET /offers → Paginated<Offer>; параметры q, category, category_id, supplier_id, stock_status, region, page, per_page
GET /offers/{id} → { data: Offer }
GET /suppliers → Paginated<Supplier>; параметры q, city, page, per_page
GET /suppliers/{id} → { data: Supplier }
Чего в API пока нет: отправки заявки (POST), серверного подбора поставщиков, параметра сортировки, группировки офферов по поставщикам.

Правила разработки
Цвета, радиусы и отступы — только через токены. Захардкоженных значений вроде bg-[#060816], border-white/10, text-cyan-300 в JSX быть не должно.
Каждый экран работает в светлой и тёмной теме. Проверять обе.
Данные читаем на сервере. "use client" — только там, где есть интерактив, и как можно ниже по дереву.
Состояние экрана (фильтры, шаги визарда, страница) живёт в URL, не в useState. Ссылка на выдачу должна открываться напрямую и работать с кнопкой «назад».
Компоненты shadcn ставим командой npx shadcn@latest add <name>. Файлы в src/components/ui/ руками не правим — нужна вариация, делаем обёртку.
У каждого поля есть подпись. Интерактивные элементы доступны с клавиатуры. Декоративные глифы — aria-hidden.
Ошибки API ловим через ApiError, показываем текст и кнопку «Повторить». Пустые состояния — отдельный экран, не пустая сетка.

Что временное
/categories снова отвечает на проде, жёлтый баннер про недоступный маршрут убран. Фолбэк на PILOT_CATEGORIES пока оставлен — снимаем, когда убедимся, что маршрут стабилен.
Сортировка в каталоге работает только по загруженным офферам группы — параметра сортировки в API нет.
Параметр page в каталоге листает группы поставщиков, а не офферы: группировку собираем сами запросами по supplier_id.
API живёт на IP через sslip.io. Домен появится позже, тогда правим remotePatterns в next.config.ts.
Заявка копится в localStorage и никуда не уходит — POST-эндпоинта нет. Отправка с /request имитируется: заявка складывается в localStorage ключом agora-submitted-requests, номер выдаётся сквозным счётчиком. Оттуда же её читает экран «Мои заявки». Когда появится POST, меняем только src/hooks/use-submitted-requests.ts.
Заявка в корзине может содержать офферы разных поставщиков, а одна заявка уходит одному поставщику. На оформлении позиции режутся по поставщикам, и отправка создаёт по заявке на каждого. Это подтверждено комментарием в макете (#5). Выделение стоит в шапке каталога, рядом с «Каталог предложений»; на оформлении оно продублировано бейджем у каждой группы, а при нескольких поставщиках есть ещё и плашка.
Вторая половина того же комментария — «индикация, что поставщик подходит» — не сделана: в API нет признака, по которому поставщик считается подходящим. Надо уточнить у Екатерины, что это значит.
По комментарию в макете (#12) регистрация обязательна, и из заявки надо уводить на регистрацию. Экрана регистрации ещё нет, поэтому на оформлении стоит только вход в него — заглушка. Когда экран появится, отправку без аккаунта надо запретить.
Картинку на экране успешной отправки (комментарий #13) отдаст Екатерина, пока в слоте заглушка с иконкой.
Авторизации нет ни в коде, ни в макетах, поэтому «Вход и регистрация» в шапке показывает уведомление-заглушку. Экраны входа и регистрации обещаны позже.
Токены --warning и --success добавлены в globals.css под оранжевые предупреждения и зелёный заголовок успеха: в палитре shadcn Neutral таких цветов нет.
Контакты поддержки в src/lib/site.ts взяты из макета, реальных пока нет.
